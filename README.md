# Mary Hardy | Portfolio

A fully responsive personal portfolio landing page built with semantic HTML5 and Tailwind CSS v4.

## Features

- Responsive layout across mobile, tablet and desktop
- Custom Tailwind v4 theme with brand color tokens
- Hero section with floating badges
- About section with personal info cards
- Skills section with hover interactions
- Resume section with timeline UI for education and experience
- Contact form with social links
- Dark footer with consistent purple design system

## Tech Stack

- HTML5
- Tailwind CSS v4
- Font Awesome 6
- Google Fonts (Open Sans)

## Getting Started

clone the repository then run:

npm install
npm run dev
